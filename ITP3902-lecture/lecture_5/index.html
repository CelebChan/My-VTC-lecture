03 / CYCLE TESTS

两种回路，两个问题

Euler 看边，Hamilton 看点。下面的两个小工具把 PPT 的判定条件变成可以即时检查的状态。

A

EULERIAN

每条边都走到吗？

YES

Eulerian cycle：经过每条 edge 恰好一次，并回到起点。

满足两个条件：这是 Eulerian graph。
connected + all degrees even ⇔ Eulerian
B

HAMILTONIAN

每个点都访问吗？

CHECK

Hamiltonian cycle：经过每个 vertex 恰好一次，并回到起点。

Dirac：3 ≥ 6/2，满足充分条件。
Dirac: δ ≥ n/2Ore: d(v)+d(w) ≥ n
